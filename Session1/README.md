# Session1 — Web サイトを動かして編集する

## このセッションで学ぶこと

`web/` フォルダにある **静的ウェブサイト** を Codespaces 上で動かし、
HTML / CSS を編集して見た目を変えてみます。

```
web/index.html  ──→  Codespacesのポート8000（転送URL）  ──→  ブラウザに表示
       ▲
   Codespacesで編集して保存 → ブラウザを再読み込みすると反映される
```

> このサイトは Session2・Session3・Session4 でも引き続き使います。

---

## 使用するファイル

| ファイル | 役割 |
|---|---|
| `web/index.html` | サイト本体（文章・フォーム・JavaScript） |
| `web/styles.css` | デザイン（色・余白・フォントなど） |
| `web/photo1.png` | おすすめ風景①（かぐらスキー場） |
| `web/photo2.png` | おすすめ風景②（富津海岸から望む富士山） |

---

## Step 1 — サイトを起動する

Session0 でやったように、Codespaces のターミナルでサーバーを起動します。

```bash
cd web
python -m http.server 8000
```

「ポート 8000」の通知の **「ブラウザで開く」**、または **「ポート（PORTS）」** タブから
転送URL（`https://<英数字>-8000.app.github.dev`）を開きます。

> ⚠️ サーバーは起動したままにしておきます。編集 → 保存 → サイトのタブを再読み込み、の流れで開発します。

---

## Step 2 — 文章を変えてみる

`web/index.html` をエディタで開き、ホームのあいさつ文を探します。

```html
<section id="home">
    <h2>ようこそ</h2>
    <p>私たちのウェブサイトへようこそ。...</p>
```

`<h2>ようこそ</h2>` を、自分の好きな見出しに書き換えてみましょう。

```html
<h2>ようこそ、<あなたの名前>のサイトへ！</h2>
```

保存したら、ブラウザを **再読み込み（F5）** して変化を確認します。

---

## Step 3 — 色を変えてみる

`web/styles.css` を開き、ヘッダーの色（`header` の `background-color`）を探します。

```css
header {
    background-color: #005bac;   /* ← この色を変える */
    color: white;
    ...
}
```

例えば緑系に変えてみます：

```css
    background-color: #2e8b57;
```

保存 → ブラウザ再読み込みで、ヘッダーの色が変われば成功です。

> 色は `#005bac` のような **カラーコード** で指定します。`red` / `green` のような名前でも書けます。

---

## Step 4 — 写真を差し替えてみる（任意）

`web/photo1.png` を、自分の好きな画像（同じファイル名 `photo1.png`）に置き換えると、
おすすめ風景①の写真が変わります。

Codespaces では、左の **エクスプローラー** の `web/` フォルダに画像ファイルを
**ドラッグ＆ドロップ** すると追加できます（同名で上書き）。

> ファイル名・拡張子（`.png`）はそのままにしてください。HTML 側の `<img src="photo1.png">` と一致させる必要があります。

---

## できたこと

- Codespaces で自分のサイトを表示できた
- HTML（文章）と CSS（デザイン）を編集して反映できた

この時点では「会員登録」「AIおすすめ」ボタンはまだ動きません。
次の Session2・Session3 で、事務局が用意した **API** につなぎます。

## よくあるトラブル

| 症状 | 対処 |
|---|---|
| 画面が真っ白 / 404 | `web/` フォルダの中でサーバーを起動しているか確認（`cd web`） |
| 編集が反映されない | ファイルを保存（`Ctrl + S`）したか確認 → サイトのタブを **強制再読み込み**（`Ctrl + Shift + R`） |
| 写真が出ない | ファイル名が `photo1.png` / `photo2.png` と一致しているか確認 |
| サイトのタブが開けない | 「ポート（PORTS）」タブでポート `8000` が転送されているか確認。なければサーバーが起動中か確認 |
| `python` が見つからない | `python3` を試す。Codespaces には通常 Python が入っています |
